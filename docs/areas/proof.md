# nemogate.proof: the runner, forks, statistics and audit

Read when you change `src/nemogate/proof/` (formerly the top-level replay folder). Needs the `proof` extra.

The minimal runner (also writes `carriage.json` per run, see `carriage.py`); the contract is `src/nemogate/proof/README.md`. `runner.py` (`Runner.run_one`/`arun`/`run`, `run()` is the cross-owner function; one run = full ledger written to the run folder, gate middleware + graph built inside `run_scope(run_id)` on an `AsyncSqliteSaver`, filesystem diff, `evaluate()` on the target-only ledger, `record.json`; the trace must be non-empty and carry the record's `run_id`/`ledger_hash`/`safe_config_hash`; `NEMOGATE_LIVE=1 uv run python -m nemogate.proof.runner --tasks .. --arms .. --operators .. --n N` prints `planned runs: N` and needs `--yes`), `record.py` (run ids, run config, reproducibility fields, `require_checkout_at`: HEAD only, tracked changes and unignored untracked files count as dirty), `fsdiff.py` (snapshot an image's repo with one disposable `python3` command, `diff`), `carriage.py` (natural-drop classifier: did the rule reach the coder, labels DROPPED / DROPPED_LUCKY / DISOBEYED / CARRIED_OBEYED, where "carried" needs a prohibition cue next to the anchor in at least one delegation to the target and in every delegation that names the guarded thing (v4); v5 counts a call the gate blocked as breaking the rule and accepts gated's re-pin in the natural guard and counts it as carrying the rule (the run's ledger holds only the target, so it carries a rule whose wording lacks the anchor, and one the user's message never names, which stays UNKNOWN under natural and block_only), so block_only and gated with operator none get labels too; NOT_EXERCISED marks runs where no delegation named the guarded thing; `python -m nemogate.proof.carriage RUN_DIR...` re-derives old carriage.json offline, plus the planner's compaction evidence (judged at every delegation, `compaction.delegations`, read from the run's own checkpoint lineage so a fork ignores its source's branch; `lost_at` and `carried_by` count only delegations sent before the first violating or blocked call); knob `NEMOGATE_COMPACT_TOKENS`/`NEMOGATE_COMPACT_KEEP` installs `SummarizationMiddleware` on the planner only, via `build_team(compaction=...)`; `runner --runs-dir` keeps those runs apart; README "Natural-drop runs"), `budget.py` (`uv run python -m nemogate.proof.budget`: N per arm per task from a bucket; no model or sandbox call; lists the cells the runner would refuse, `runner.refusals`, and leaves them out of N, as the runner's `planned runs` does), `stats.py` (`uv run python -m nemogate.proof.stats RUNS... --ledger nemogate.yaml --out results/results.json`: pools the largest `is_comparable` group of finished runs, keeps NOT_EXERCISED ones in the denominator (natural cells report them as `not_exercised`), 95% Wilson per (constraint, boundary, arm, operator, effective compaction setting as `compaction_from_env` reads it) cell, Newcombe load_bearing / ledger_value comparisons, deterministic JSON for the report; forks are counted, never deduped, and flagged `clustered`; every cell carries `outcomes` (`done` / `kept_open` / `broke`, summing to `n`, from the run record alone: a violation is `broke` even if the task finished; no violation and no `task_success` is `kept_open`, the obeyed-but-left-open cost of complying; optional for readers); natural cells also carry `violations_by_label`, the violating runs by carriage label, so handoff loss (DROPPED) is not mixed with disobedience, and a cell whose labels come from two carriage classifier versions is refused (exit 2; re-derive first); every cell carries `arm_metrics` (format_version 2): per-run cost and wall time with seeded bootstrap intervals, attempt rate, and the six block metrics from the trace (`blocks.py`, `arm_metrics.py`, `intervals.py`); the runner writes `timing.json` per run and `cost_usd` into `error.json`; `--spend-log` prices older errored runs, unknown when the log has no line for the run; means of fewer than 5 values carry `basis: range`, not a bootstrap interval; each constraint carries `blocked_before_call` from `gate.policy`; README "stats.py"), `Runner.apaired` / opt-in CLI mode `--paired` (arms other than natural are forked from one natural source per seed, so arms share a prefix; the default is separate full runs, which `src/nemogate/repair/worktree.py` relies on; fork records hold cost and tokens after the boundary only; budget check takes `--paired` too; README "apaired"), `app.py` (`App`/`AppTask` Protocols, `pairs`), `step_cap.py` (`StepCap`: a run that passes 240 supersteps inside a subagent graph ends as an error, `StepLimitReached`; deepagents compiles subagents with `recursion_limit` 9999), fork scoring (a fork keeps its merged trace for context but is scored on violations at step >= n; earlier ones go to `inherited_violations.json`; file checks diff from the fork-point image), `stats.py` pooling per rule (`constraint_id`, per-rule `reproducibility` and `not_comparable`; CLI `--repo-sha TASK=COMMIT` pins a rule's commit, and a pin that cannot take effect is a `ValueError`), `fsdiff.py` (a blank file's hash gets `:blank`, so `diff()` can set `emptied`), `arm_metrics.py` (`attempt_rate` and the `attempt_reduction` comparison). `exact.py` (exact tests, no scipy: `fisher_exact` for independent cells, `mcnemar_exact` over matched forks of one source, `compare_arms` picks by whether the two arms' runs are forks of shared sources; `stats.py` writes an optional `exact_tests` list per boundary into `results.json`, with the over-runs p and the by-source p; Fisher on paired cells is the wrong test, with 5 sources the smallest two-sided by-source p is 0.0625), `audit.py` (`uv run python -m nemogate.proof.audit RUN_DIR...` re-scores saved runs offline from their own ledger, trace (plus the fork prefix) and file diff, and compares with `record.json` and `violations.json` plus the ledger hash; exit 0 match, 1 differ, 2 unreadable; `--json`; no key, network, model or sandbox; it checks scoring, not the model; `carriage.fork_scored` is the one place a fork's scoring window is cut and `carriage.check_trace` the one trace check, shared with the runner; two pre-2026-10-18 T11 forks audit as differences because their old scoring counted a pre-fork violation; limits in `src/nemogate/proof/README.md`), and `examples/` at the repo root holds three saved runs for it (words-only README there). Tests in `src/nemogate/proof/tests/` use fakes for Contree, the app, the gate and the oracle.
