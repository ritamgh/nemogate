## Gotchas

- The seed and the task overlays need Flask, which the nemogate env does not have; run them only through `refapp/seedenv.py` (local) or `refapp/sandbox.py` (Contree). Running pytest in a repo writes `__pycache__`/`.pytest_cache`, which would pollute a run's filesystem diff, so every test command sets `PYTHONDONTWRITEBYTECODE=1` and `-p no:cacheprovider`. Disabling the general-purpose subagent is process-global (FACTS section 7).
- SQLite checkpoints (`*.sqlite`, `*.db`) and the gitignored runs folder are never committed. If the reference app ever needs a committed seed DB, add an exception in `.gitignore`.
- Second app (Oct 24-27): the research team with a cached Tavily search tool (`refapp/research/`, task T13 and the higher-base-rate T14, rule C-011); `NEMOGATE_APP=module:attr` selects the app, default unchanged; details in `refapp/README.md` "Research app" and SPEC Changes 2026-10-25.
