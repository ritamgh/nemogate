# nemogate.repair: the repair agent

Read when you change `src/nemogate/repair/` (formerly the top-level repair folder). B's folder; list changes for B's review.

- Flow (SPEC C5): the planner model picks a fix from a closed menu (`menu.py`: `carry_rules`, `no_rule_compression`, `require_output_format`, which put the rule in front of the handoff), the SUT model writes an insert-only patch (`patch.py`), guards check it (`guards.py`), a subset of runs is re-run on the patched commit in a worktree (`worktree.py`, which relies on the runner's default separate full runs, not `--paired`), and the patch is accepted or rejected deterministically (`loop.py`). `python -m nemogate.repair` runs one round and spends credit, so it needs `NEMOGATE_LIVE=1` and `--yes`.
- `guards.py` `_PROTECTED_DIRS` matches path components (schemas, common, ledger, oracle, gate, proof, repair, report, preflight, tests, tasks, docs, .github), so `src/nemogate/gate/...` is protected; ledgers, configuration and lock files (`.yaml`, `.yml`, `.toml`, `.lock`) are protected by suffix. Anything else under `src/nemogate/` (modules directly in it, new folders) is protected too ("the package's own code"). Tests pin that every package folder and every module directly under `src/nemogate` stays protected.
- The writer only inserts text into prompts. A retry that echoes the guard's error does not fix a mistyped quote, so `anchor_hints()` lists real lines (PR #83), and the guard refuses an insert right after a backslash continuation or one that touches the text around it with no space or newline (PR #87, found by the live round 2 patch that read "user.Copy"). Whole-line anchors are suggested to the writer, not enforced. Prompt-only fixes did not move the planner in the live round; the gate is what works.
- PR #104: repair always writes a summary and kills the runner's descendants on a kill.
